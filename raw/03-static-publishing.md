# 課堂隨記：靜態網站與 GitHub Pages
2026-11-06

靜態網站可以由 HTML 結構、CSS 樣式、JavaScript 互動組成。資料可先整理成 notes.js，讓畫面由資料產生，不把每張卡寫死在 HTML。
若要雙擊 index.html 直接用，這次用傳統 script 載入 window.NOTES，不用 fetch 讀本地資料。
GitHub Pages 可發布 repository 中的靜態檔案，這份練習沒有後端或資料庫。入口叫 index.html。
專案網址可能有 repository 子路徑，資源連結使用相對路徑，避免 /assets 這種根路徑。
發布前測試搜尋、分類、標籤、詳情與手機畫面；這也是驗證 Agent 是否完成任務的具體例子。
